# Oxygen · 参考图驱动网页设计

一个面向中文 UI、展示页、活动落地页与 HTML 原型的个人 AI 技能。

保留需求梳理、结构规划、分区实现和交互检查流程；视觉遵循用户参考图，不强制模板审美。

## 使用

将本目录放入支持 SKILL.md 的工具所使用的个人技能目录。
例如 Comate 的个人目录为 `C:\Users\<用户名>\.comate\skills\oxygen-reference-web-design\`。
安装前遵循所用工具的技能检查流程。重新加载后，以实际技能列表为准。

也可以把 SKILL.md 作为上下文提供给 AI，并要求遵循其中规则。
本技能本身不提供模型、Figma 连接、浏览器或图片生成工具。

示例：

> 使用 oxygen-reference-web-design，按我提供的参考图制作中文展示页。先给页面大纲和首屏方案，确认后再实现。

## 工作流程

1. 梳理用途、用户、设备和素材。
2. 分析参考图，给出页面大纲及首屏方案。
3. 按用户确认的阶段实现。
4. 验证中文排版、移动端布局及实际交互。
5. 说明修改内容、运行入口、预期结果和排错材料。

评价与业务数据只使用用户提供或确认的真实材料。
没有后台时明确说明本地原型的能力边界。

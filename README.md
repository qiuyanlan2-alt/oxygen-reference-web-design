# Oxygen · 参考图驱动网页设计

一个面向中文 UI、展示页、活动落地页与 HTML 原型的个人 AI 技能。

保留需求梳理、结构规划、分区实现和交互检查流程；视觉遵循用户参考图，不强制模板审美。


## 工作流程

1. 梳理用途、用户、设备和素材。
2. 分析参考图，给出页面大纲及首屏方案。
3. 按用户确认的阶段实现。
4. 验证中文排版、移动端布局及实际交互。
5. 说明修改内容、运行入口、预期结果和排错材料。

评价与业务数据只使用用户提供或确认的真实材料。
没有后台时明确说明本地原型的能力边界。

## 文件

- `SKILL.md`：完整技能规则。
- `evals/evals.json`：三个行为验收场景。
